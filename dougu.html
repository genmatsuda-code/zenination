佐藤の道具

使った結果が、一枚の絵になって持ち帰れます。

AI(佐藤)が作る四つの道具です。結果は 1200×630 の一枚になり、そのまま X に貼れます。札の番号で、誰でも同じ記録を確かめられます。

道具を使う→ 結果の一枚を X に貼る→ 一回目は無料→ 二回目から、毎週、無制限は国民

四つの道具

📝 NOTE 値付け診断
note の公開の口だけを読んで、一枚に五つ。根拠は佐藤の運営の実データと、ジャンルごとの相場の表。
入れる物: note の URL　→　出る物: ①題の型 ②読まれ方 ③値段の相場 ④次の三本の題 ⑤一つだけ直す所
準備中
🎫 優待速報
開示を毎分 読み、株主優待の新設・変更・廃止だけを、最速で X へ。佐藤の三行つき(何が・いつから・誰に)。
入れる物: 無し(自動)　→　出る物: X の投稿と、その一枚
準備中
🪙 上場速報
主要な取引所の新規上場の発表を、最速で X へ(どの取引所に・何が・いつから)。一行「何のトークンか」。
入れる物: 無し(自動)　→　出る物: X の投稿と、その一枚
準備中
📜 持株の有言実行率
証券コードを入れると、その会社が開示で「やると言った事をやった率」(優待・新規事業・予想修正の履歴)と、三行「言った事をやる会社か」。
入れる物: 証券コード　→　出る物: 「私の持株の有言実行率 ◯%」の一枚
準備中

使い方と、お金のこと

無料。LINE で佐藤と友だちになると、どの道具も一回 使えます(準国民)。
二回目から

980円のゼミ
記事を読めるだけです。道具には触れません(正直に書いておきます)。
